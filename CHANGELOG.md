# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.2.0] - 2026-10-29

### Added

- Laravel 13 support.
- PHP 8.3 and 8.4 officially supported and tested.
- New `routes` configuration section (`enabled`, `prefix`, `middleware`) to
  customise or disable the download route. Defaults reproduce the previous
  behaviour.
- `DOCSTORE_DISK` environment variable for `storage_disk`.
- `X-Content-Type-Options: nosniff` header on downloads.
- The configured visibility resolver is now validated: a class that does not
  implement `DocumentVisibilityResolver` throws an `InvalidArgumentException`
  instead of failing later with a type error.
- GitHub Actions workflow testing every supported PHP × Laravel combination,
  plus PHPStan and Pint checks.
- Tests for successful downloads, inline/attachment handling, missing files,
  unknown documents, authentication, folder paths, ordering and size formatting.

### Changed

- `php` constraint narrowed from `>=8.2` to `^8.2`.
- The package now declares the Illuminate components it actually uses
  (`console`, `database`, `filesystem`, `http`, `routing`, `support`) instead of
  `illuminate/support` alone.
- `Document` and `Folder` declare their table (`documents`, `folders`) and
  foreign keys explicitly, so subclasses may use any class name.
- The download controller and all relations resolve models consistently through
  `Document::model()` / `Folder::model()`.
- The migration stub declares `void` return types.
- Development tooling files are excluded from Composer dist archives.
- README rewritten: compatibility table, upload example, access-control warning,
  route customisation, data model reference and upgrade notes.

### Fixed

- **Download file names are now safely encoded.** The `Content-Disposition`
  header was built by string concatenation, so a file name containing a double
  quote produced a malformed header and non-ASCII names were not encoded per
  RFC 6266. It is now generated by the filesystem adapter (Symfony `HeaderUtils`).
- `Folder::documents()` used a foreign key derived from the class name, which
  broke for subclasses not named `Folder` (e.g. `ProjectFolder` looked for
  `project_folder_id`). It now always uses `folder_id`.
- Subclasses not named `Folder` / `Document` looked for a non-existent table
  (e.g. `custom_folders`); covered by the explicit table names above.
- `Folder::$full_path` no longer recurses infinitely when the hierarchy contains
  a cycle.
- `routes/web.php` imports the `Route` facade explicitly instead of relying on
  the global alias.

### Removed

- Unused `laravel/passport` development dependency.

## [1.1.1] - 2026-06-20

### Fixed

- `Folder::parent()` and `Folder::children()` now use the model returned by
  `static::model()` instead of hard-coding `self::class`. Applications extending
  `Folder` (via `docstore.models.folder`) previously got base `Folder` instances
  from these relations, silently losing their own casts, accessors and relations.

## [1.1.0] - 2026-06-19

### Added

- Laravel 12 support.
- MIT license file and a complete README.
- PHPStan / Larastan configuration (level 6) with typed Eloquent relations.

### Changed

- Composer constraints cover Laravel 10, 11 and 12.
- Stronger typing across models, commands and services.
- Simplified download path handling.

### Fixed

- PHPStan errors on Eloquent relations and model properties.
- Test suite bootstrapping with Pest and Orchestra Testbench, including
  migration loading and download controller tests.
- Visibility resolver contract implementation.

## [1.0.0] - 2025-11-20

### Added

- Initial stable release.
- `Document` and `Folder` models with configurable classes and storage disk.
- Authenticated download controller with a pluggable visibility resolver.
- Publishable configuration and migration, `docstore:install` command.
- Laravel 10 and 11 support, Pest test suite with Orchestra Testbench.
